# yoga-collective
The website for Seattle Yoga Collective

### Change the website's text
The folder `yoga-collective` has all the HTML pages. HTML uses tags to define the structure of the document. For example, if you wanted to make a title on your home page, you would build it like this:

```
<h1>Home Page</h1>
```

Do not make changes to the tags unless you know what you're doing! Instead, make changes inside the tags. Github will use different colors to identify the tags vs the text, so it will be easy to tell which text is safe to edit.

When you're done, press the button that says "Commit changes". Then, select the option that says "Commit directly to the main branch." Once you've committed your change, it will appear on the public website.
